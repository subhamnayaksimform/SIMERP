# Goals module — what changed in SimERP 6.3.x (live observation 2026-10-07)

Environment: https://simerp-dev.simform.solutions, footer reads **SimERP 6.3.2**.
Previous baseline: 6.2.0 three-tab layout (see `2026-09-22-goals-module-relocation-review.md`).
Raw captures (aria snapshots + screenshots): `reports/knowledge-base/dom-snapshots/EMPGOL-6.3.2-explore/`.
Old automation archived (untouched copy) in `archive/goals-6.2.0/`.

## Release notes (from /whats-new)

- **v6.3.0 (29 Sep)** – Goals: Learning Objectives / Definition of Done / Topics & Concepts / Estimated Duration on Add/Edit; dashboard chart actions + legend + clearer doughnut colours; filters kept when switching tabs; RMs (non-admin) see "Your Team Goal Status" and "L&D Hours by Team Member" (one bar per person), admins see one bar per RM; Goals table Name column shows goal name first then certificate code in muted text, name sort is alphabetical; Goals no longer fetches the full employee list (load 10-12 s → 2-3 s); Estimated Duration unset units show a real 0, clicking selects contents. General: empty values read "Not specified" instead of a dash; narrow columns keep sort/filter buttons visible (full name on hover).
- **v6.3.1 (30 Sep) "Faster Goals"** – each tab loads only while open and reuses data when switching back with the same filters; Department filter starts on All Departments; changing Year/Department refreshes only the open tab; employee goals uses server-side paging, filters and search; cancelling a request on purpose no longer shows "Unable to reach the server".

## Current structure (live)

Route `/employee/goals`. H1 "Goals", breadcrumb Employee > Goals.

**Top-level tabs (2, was 3):** `Dashboard` (default, no tab param) and `Goals` (`?tab=goals`).

**Shared filter group** `group "Goal filters"` above content, on both tabs:
- `combobox "Year"` – All Years (default) / 2026 / 2025
- `combobox "Department"` – All Departments (default) + ~35 departments (listbox "Suggestions", searchable)
- `combobox "RM"` – All Managers (default) + every RM (Admin only)
- `combobox "Timeframe"` – Last 5 days / Last 15 days (default) / Last 30 days / Last 3 months / Last 6 months / All time

**Dashboard tab**
- `group "Goal KPIs"`: Total Employees (3,648), Employees with Goals (2,425), Goal Assignments (8,661), L&D Hours (157,867h, info icon "Non-billable hours logged in the selected timeframe"), Billable Hours (161,518h, info icon "Billable hours logged in the selected timeframe")
- h2 "Goal Tracking Health" – doughnut, legend Completed / Delayed / In Progress / Not Started
- h2 "Employee Goal Coverage" – legend Goals Assigned / No Goals
- h2 "RM-wise Goal Status" (Admin) / "Your Team Goal Status" (TM, EM, PM, PMO) – bar chart with `group "Zoom range"` (Zoom in / Zoom out / Reset zoom, the last two disabled initially), `checkbox "Show as separate charts"`, legend Completed/Delayed/In Progress/L&D Hours by RM/Not Started, `slider "Pan chart"`, caption "Showing 1–400 of 400 RMs · Ctrl + scroll to zoom · drag slider to pan"
- h2 "Completion by Goal" – `button "View All"`, `textbox "Search goals"`, sort button "Sort goals: Completion, high to low", list of `button "View assignments for <goal>"` each with `progressbar "Average completion"` + %, status "Showing 1–5 of 49 goals", `combobox "Rows per page"` (5), `navigation "Goal list pages"`
- h2 "Most At-Risk Goals" – same controls, sort "Sort goals: Employees, most first", items carry `img "At risk"` + "N emp"
- `View All` opens `dialog "Completion by Goal"` (or the at-risk equivalent) with full list + search + sort
- `View assignments for X` opens `dialog "<goal name>"`: `textbox "Search employee or manager"`, "N assignments", table Employee / Reporting Manager / Status / Completion % (sortable, filterable), pagination, `button "Close"`

**Goals tab** – inner `tablist "Goals view"`: `By Employee` (default) and `By Goal` (`?tab=goals&view=catalog`)

*By Employee* (old "Employee Goals"): `textbox "Search employee"`, `button "Table options"` (dialog with drag-to-reorder + `switch` per column: Reporting Manager, Goals, Overdue Goals, Certificates, L&D Hours). Columns: Show goals (expander) | Employee | Reporting Manager | Goals | Overdue Goals | Certificates | L&D Hours — each sortable and filterable; numeric filters are a range popover (`slider "Minimum"`, `slider "Maximum"`, Clear, Save). Server-paged: "Showing 1 - 100 of 3648 results", `navigation "Pagination Navigation"`. Each data row is followed by a hidden detail row; expander cell "Show goals" (clicking `getByRole('button', {name:/Show goals/})` timed out — the expander may be the cell/row itself, ground it).

*By Goal* (old "Goal Management"): `textbox "Search"`, `button "Add Goal"`, columns Action (Edit, Delete — Delete disabled when goal has assignments) | Goal Name (sort/filter; certificate code appended in muted text, e.g. "Kubernetes Administrator (CKA)CKA") | Type (sort/filter) | Description | Assigned Emp. (Dept.) (button with count) | Assigned Emp. (Org.) (button with count). Server-paged "Showing 1 - 100 of 545 results". Many leftover automation goals named like `TC090-1784178384069` with count "None".

**Roles (live)**: Admin (ceo) full incl. RM filter. PMO, EM, TM: Year + Department (All Departments) + Timeframe, chart titled "Your Team Goal Status". PM: Year + Timeframe only (no Department). CSM, Employee (kashyap), punit → `/unauthorized`.
**Possible regression to verify:** TM previously had NO Department picker and was locked to own department; TM now sees "All Departments" — check whether TM data is org-wide (data leak) or still scoped.

**API (new):** `GET /api/v1/employee-goals/dashboard`, `GET /api/v1/employee-goals/filter-options`, `GET /api/v1/employee-goals/employees`, plus `/employees/metadata`, `/employees/permissions`, `/shared/feature-flags`. API origin `https://simerp-dev-api.simform.solutions`.
