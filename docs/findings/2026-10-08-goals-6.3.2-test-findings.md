# Goals module 6.3.2: end-to-end test findings (2026-10-08)

Suite: `tests/e2e/employee/goals/` (147 tests, TC-EMPGOL-401..547), cases `reports/test-cases/cases-2026-10-07-EMPGOL-goals-v632.json`.
Run: chromium, 1 worker, dev (simerp-dev). Final result: **109 passed, 2 flaky (passed on retry: 427, 486), 3 skipped (manual), 33 failed**.

Every one of the 33 failures is a test that asserts the correct behaviour and carries a `defect` annotation. Tests that failed because of test or environment problems were fixed and re-run:
- 429: name-sort comparator. Fixed.
- 494: toasts covering the Goal Name field. Fixed.
- 414–416, 511: the chart's new 25-bar default window. Fixed.
- 444–452: a DNS drop on my side during the run. Re-run.

The results of those re-runs are merged into `reports/results/results.json`.

**Changed during this session:** between 2026-10-07 and 2026-10-08 the RM / team chart started opening on a 25-bar window ("Showing 1–25 of 400 RMs"). Before, it showed all bars. Zoom out and Pan are active from the start, and Reset zoom is off until you zoom. No release note mentions this, and the app version still reads 6.3.2.

- The TM Department picker is scoped to the TM's own departments, so there is no leak.

Note: a cold Dashboard load took about 7 s, above the 2–3 s in the release notes. The performance test passed on retry.
